# Hundred Step: study plan

This plan precedes study results. Source inspection and the family report are prior knowledge; no study runs exist yet. The honesty pilot supplies only layout and shared statistics. This git plan is not an independent public preregistration. No external deposit or publication is authorized.

Construct: preserving exact step dependencies and recovering from specified faults across long synthetic workflows. Use all 24 public tasks at the frozen source commit in config.json. No hidden evaluation or human study.

H1: a reactive controller reaches full completion; empty, constant, echo, refusal, and repeated-first-call policies do not. H2: disabling recovery or allowing only transient retries prevents completion. H3 (simulated): increasing independent per-step omission probability reduces completion, while recovery improves completion under matched simulated draws. These are descriptive validation hypotheses, not learned-model claims or significance tests.

Controls: oracle (package reference), reactive, no-recovery, retry-only, stale-token, empty, constant yes, echo, refusal, first-tool. Run each through runTasks and a ModelAdapter using the public runner. Reactive reads prior tool outputs; only oracle uses fault metadata. End at the first failed action for stale-token; first-tool makes one call then ends. Standard package budgets. Repeat each control once. Re-score all traces with the public replay grader; challenge the grader with forged finalState on empty traces.

Extra virtual experiment: simulated agents on all tasks, omission probabilities 0, .005, .01, .02; recovery enabled or disabled; seeds 1 through 24. Before each new logical advance, draw once from a seeded generator; omission ends the episode. Retries do not draw again. Match draws across control conditions and probabilities. No changes to environment faults. Fixed grid: 4608 simulated episodes. Store calls and grader state; repeat the whole grid and compare semantic hashes. This simulated population measures stipulated errors, not model behavior.

Primary metric: replay final completion. Secondary: replay survival, recovery count, rollback count, composite score, calls. Wilson 95% intervals on control completion across tasks are descriptive reference intervals, not random-sample guarantees. Cluster bootstrap control score and survival over six workflow families, 2000 draws. For simulation, bootstrap seed-level task means (24 seed clusters, 2000 draws); preserve pairing for recovery contrasts and hazard contrasts. Report per-length completion with the same seed bootstrap. Boundary intervals may collapse; explain the deterministic cases. No pooled independent-task claim for simulation.

No exclusions, outlier removal, adaptive sample size, or paid inference. Runner errors fail the experiment rather than silently dropping rows. No configured free hosted arm; provider availability will not be inferred. Stop when the fixed controls, repeats, and grid finish. Record changes here before affected runs. Figures: fault coverage by length, control completion, simulated completion by length and omission probability. All numbers derive from generated files. Failure checks: fabricated final states must not pass; repeat hashes must agree; summary must reconcile with replay; no claimed completion may omit required steps.
